# Feature Checklist

Use with `/mythos:do` for new feature work.

## Before Starting
- [ ] Outcome defined in one observable sentence
- [ ] Success criteria are measurable (not "it works")
- [ ] Architectural impact noted — does this change data model, API contracts, or file structure?

## During
- [ ] Tests written before or alongside implementation (not after)
- [ ] Non-trivial decisions logged to `.mythos/memory/decisions.md`
- [ ] No scope creep — if requirements expand, surface before continuing

## Before Calling Done
- [ ] All acceptance criteria in outcome definition are met
- [ ] Evaluation score ≥ threshold in `standards.md`
- [ ] HIGH-tier actions (deploy, push, delete) confirmed with user
- [ ] Any architectural decisions saved to memory
