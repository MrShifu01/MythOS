# Example: Frontend Evaluation — FAIL (44/100)

**Feature:** Settings page for MythOS project configuration
**Domain:** Frontend rubric

## What was built
A settings page with a form for editing project config. Purple gradient header, white cards,
default shadcn/ui form components with no customisation. No loading state on save. No error
handling on form submission failure. Mobile layout is broken below 768px.

## Playwright Findings
- Form fields render and accept input — works
- Save button: clicks, shows no feedback while saving — **no loading state**
- Successful save: page does not confirm — **no success feedback**
- Failed save (API error simulated): page shows nothing — **silent failure**
- On mobile (375px): form overflows viewport, fields are clipped — **broken**
- Empty state (no config saved yet): form shows with empty fields — acceptable

## Dimension Scores

**Functionality: 45/100** — Core form submission works but the UX is broken:
no loading state, no success confirmation, silent failure on error. Users cannot tell
if their settings were saved. On mobile, the form is unusable.

**Design quality: 40/100** — The page feels like three unrelated components placed vertically.
The purple gradient header clashes with the card backgrounds. No visual hierarchy guides
the user's eye. It does not feel like a designed page.

**Originality: 25/100** — Unmodified shadcn/ui Card components throughout. Purple gradient
is the single most common "AI-generated UI" pattern. Zero distinctive decisions visible.
This could be any settings page generated by any AI tool.

**Craft: 55/100** — Typography is readable. Spacing is mostly consistent. Mobile is broken,
which is a hard craft failure.

**Composite: 44/100 → fail — targeted**

## Verdict
`fail — targeted` — Return to Generator with dimensional feedback.

**Priority fix:** Functionality failures (no loading/success/error states) block shipping.
Fix these first — they are not aesthetic, they are broken UX.

**Pivot recommendation (if this fails again):**
Abandon the purple gradient entirely. Start from the same zinc dark system used in the
dashboard. The form should feel like it belongs to the same product.
The generic card layout needs a structural rethink — consider a sidebar + detail pattern
rather than stacked full-width cards.

---
*What made this a FAIL: Playwright revealed that users cannot tell if their settings saved.
Silent failure on form error is not an aesthetic issue — it's a broken feature.
The originality score reflects a real problem: purple-white-card is the AI default,
not a deliberate design choice. Both must be fixed.*
